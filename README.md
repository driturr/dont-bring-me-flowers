A multi-step static web challenge created for the **[HackGBGay](https://hack.gbgay.com/about.html) CTF 2026** as part of the third HackGBGay Con.

Hack GBGay is a community initiative that introduces cybersecurity to LGBTQ+ people, regardless of their background, previous experience, or whether they work in technology.

This is an easy challenge for complete beginners. It does not require tools (for most of the steps): almost everything can be found through the browser. No brute-forcing or guessing is required. It is not a technical challenge. It focuses more on curiosity, observation, and logical thinking. Players are encouraged to inspect, connect clues, make deductions, and uncover a hidden secret.


P.S. A version requiring no tools at all was submitted for the CTF.

---

# Don't Bring Me Flowers
You are browsing Sara's lesbian blog: an archive of posts, diaries, and personal moments.

Some things were never meant to be public.

Can you uncover the secret?
Find what isn't meant to be seen.

---

## Setup

1. Clone or download this repository.
2. From the project root (`NoFlowers/`), start a local web server:

   ```bash
   python -m http.server 8000
   ```

3. Open your browser at:

   ```
   http://localhost:8000
   ```

4. **Avoid browsing the project files directly**, as this will spoil the challenge. Everything is intended to be discovered through the browser.
